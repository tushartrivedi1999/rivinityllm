# Rivinity Nexus Dashboard (Next.js + shadcn-style UI)

Pages implemented:

- `/login`
- `/models` (model registry)
- `/datasets` (dataset registry)
- `/training` (training jobs)
- `/inference` (inference playground)
- `/gpu` (GPU cluster monitor)

This frontend is scaffolded with Next.js App Router and shadcn-style reusable UI components (`Button`, `Card`, `Input`, `Badge`, `Progress`).
